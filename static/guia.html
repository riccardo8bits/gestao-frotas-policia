1. Dashboard

Arquivo: templates/dashboard.html

{% for item in itens %}
<tr>
    <td><strong>{{ item.id }}</strong></td>
    <td><strong>{{ item.descricao }}</strong></td>
    <td>{{ item.categoria }}</td>
    <td>R$ {{ item.valor_unitario }}</td>
    <td>
        <span class="badge-estoque {% if item.quantidade <= 5 %}critico{% elif item.quantidade <= 15 %}atencao{% else %}normal{% endif %}">

6. Formulários (Cadastros)

Os formulários usam method="POST" e action apontando para a rota que salva no banco.

Cadastro de Policial

Arquivo: templates/cadastroPolicial.html

ONDE ESTÁ: 
<form>
    <input type="text" placeholder="000.000-0">
    <input type="text" placeholder="Ex: João da Silva">
    <select>...</select>
    <button class="btn-salvar">💾 Salvar Policial</button>
</form>
ONDE VAI FICAR: 
<form method="POST" action="/cadastrarPolicial">
    <input type="text" name="matricula" placeholder="000.000-0">
    <input type="text" name="nome" placeholder="Ex: João da Silva">
    <select name="cargo">...</select>
    <button type="submit" class="btn-salvar">💾 Salvar Policial</button>
</form>
⚠️ Atenção: Todo <input> e <select> precisa de name="..." para o Flask conseguir ler o valor no back-end.

Cadastro de Viatura

Arquivo: templates/cadastroViatura.html

<form method="POST" action="/cadastrarViatura">
    <input type="text" name="placa" placeholder="Ex: ABC1D23">
    <input type="text" name="prefixo" placeholder="Ex: V-1234">
    <select name="modelo">...</select>
    <input type="text" name="ano" placeholder="YYYY">
    <input type="number" name="odometro" placeholder="0">

</form>

7. Sintaxe Jinja2

Loop ({% for %})

Use quando você tem uma lista de itens (várias linhas de tabela, vários cards, etc).

{% for ITEM in LISTA %}
    <!-- HTML repetido, usando {{ ITEM.campo }} -->
{% endfor %}

Condicional ({% if %})

Use quando você precisa mudar o HTML dependendo do valor.

{% if condicao %}
    <!-- HTML se verdadeiro -->
{% elif outra_condicao %}
    <!-- HTML se outra -->
{% else %}
    <!-- HTML se nenhuma -->
{% endif %}

Variável simples ({{ }})

Use quando você quer mostrar um valor do back-end.

{{ nome_da_variavel }}
{{ objeto.campo }}
{{ lista|length }}   <!-- tamanho da lista -->
💡 Dica: O |length retorna o número de itens da lista. Útil para "Mostrando X de Y".
